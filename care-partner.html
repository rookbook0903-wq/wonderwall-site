現場のリアル

いま、ケアマネジャーの現場で
起きていること

記録に向き合う時間が、少しずつ増えていませんか。経過記録、担当者会議の議事録、そして最後に待ち受ける介護ソフトへの転記——。 こうした"見えない残業"が、ケアマネジャーの時間と心をじわじわとすり減らしています。

01
記録の二度手間

経過記録や担当者会議の記録を書いた後、さらに介護ソフトへの入力が待っている。同じ内容を何度も書き直す時間は、本来、利用者のために使えるはずです。

02
FAX・紙書類の仕分け

届いた順番に積み上がるFAX。1枚ずつの仕分け、リネーム、フォルダへの格納——地道で時間のかかる作業が、毎日繰り返されています。

03
介護ソフトへの最終入力

そもそも、AIで記録を整形している事業所自体がまだ少ないのが現状です。それでも——AIを活用できていたとしても、最後の介護ソフトへの転記が残る限り、時間短縮には限界があります。

04
残業・持ち帰り仕事

終業後まで持ち込まれる記録作業。本来の「人と向き合う仕事」に集中できる時間を、取り戻したい——そう感じる瞬間がありませんか。

Overview

記録を書く手間と、入れ直す手間。
その両方を減らします。

職員が話す・入力するだけで記録案ができ、AIが介護記録の書式に整えます。 職員が確認・修正して確定した記録は、事業所の転記用PCが介護ソフトへ自動で入力します。

いま起きていること
  • 訪問後にメモを起こし、あらためて文章に整える手間がかかる
  • 整えた記録を、介護ソフトの画面へ人手で入力し直している（二重入力）
  • 入力が夜間・持ち帰りになり、記録の提出が遅れる
  • 担当者会議・支援経過など、画面ごとに入力項目が違い間違えやすい
導入後
  • スマートフォンやPCで話す／フォームに入力するだけで記録案ができる
  • AIが介護記録の書式に整え、職員は確認して直すだけ
  • 確定した記録は、事業所の転記用PCが介護ソフトへ自動入力
  • 失敗した記録は管理画面に理由付きで残り、放置されない
導入効果の考え方　削減の対象は「記録を文章にする時間」と「介護ソフトへ入れ直す時間」の2つです。記録の内容そのものは職員が確認・修正したうえで確定するため、記録責任は事業所側に残ります。

職員が触るのはSTEP1〜3まで。介護ソフトのログインや画面操作は、転記用PC側で自動的に行われます。AIの出力をそのまま転記することはありません。職員の確認を経た記録だけが転記対象になります。
Product Sets

2つの記録方法と、
共通の転記アドオン。

音声で記録する方法と、フォームで入力する方法。どちらも同じ仕組みで介護ソフトへ自動入力できます。事業所ごとに、使う構成を選べます。

セット構成想定する使い方
A1音声記録のみ（保存まで）介護ソフトへの転記は使わない
A2音声記録＋介護ソフトへの転記話した内容が介護ソフトまで自動で入る
Bフォーム入力＋介護ソフトへの転記決まった項目を入力し、自動転記する
A2+Bすべて記録の種類によって使い分ける
どのセットでも使えるもの　掲示板（事業所内のお知らせ共有）・記録の履歴・CSVエクスポート・スマートフォンへの通知は、セットに関係なく標準で画面に並びます。
Features

標準機能の一覧。

選んだセットに応じて、利用できる機能が切り替わります。

記録を作る 音声アップロード／リアルタイム音声入力／Web・スマートフォンのフォーム入力 音声は wav・mp3・m4a・ogg・webm に対応。1ファイル150MB・1音声300分まで
記録を整える AIによる記録整形／整形結果の手動修正／音声での修正指示 整形の書式は記録種別ごとに設定。職員が確認して確定します
介護ソフトへ入れる 転記予約／自動転記／支援経過・担当者会議など画面別の入力／利用者・担当者マスタの同期 事業所内の転記用PCが実行。介護ソフトの画面構成は事業所設定に合わせて切替
確認・運用 記録の履歴／CSVエクスポート／転記エラーの理由表示／スマートフォンへの通知 失敗した転記は理由コード付きで残り、当社の管理画面からも追跡します
事業所内の共有 掲示板（お知らせの投稿・一覧・詳細・コメント／ファイル添付・外部リンク） 重要な投稿はスマートフォンへ通知。個別利用者の記録を共有する場所には使いません
利用量の管理 職員ごとの月間音声利用枠（既定：月25時間） アップロードとリアルタイムで同じ枠を消費。枠は事業所・職員単位で調整可能

Option

AIが自動でタスクを作る。

標準セットには含まれません。ご契約に応じて事業所単位で有効化します。

  • 確定した記録（音声・フォーム）から、対応が必要な事項をAIが自動でタスク化
  • 状態は「未着手／対応中／保留／完了」の4つ。手動での登録・コメント追記にも対応
  • 期限が近いタスク・超過したタスクをダッシュボードで警告（既定：期限3日前から）
  • 職員が見えるのは担当利用者のタスクと自分への割当て分のみ。抽出結果は職員が修正できる
「なぜこのタスクが出たのか」が残ります。AIが根拠として抜き出した記録中の記述と、元になった記録へのリンクが詳細画面に並ぶため、職員は内容を確かめてから対応できます。

実際の画面です。利用者名・職員名は仮名に差し替えています。

Security

機微な情報を扱うための設計。

扱うのは、利用者様の生活そのものに関わる情報です。開発中であっても、セキュリティは最優先で設計しています。

当社が情報を持たない 事業所に情報をまたがせない 誰が見たかの履歴を残す

動画で見る：ログイン方法とセキュリティ設定の確認（全8ステップ）

01
ログイン認証
  • 職員はパスキー（端末の顔認証・指紋認証・PIN）でログイン
  • 事業所管理者はパスキー、または同等に強い認証（TOTP等）を必須方針
  • 顔・指紋そのものは職員の端末内で完結し、当社には保存しない
  • メール認証は復旧・補助用
02
事業所間でデータが混ざらない
  • すべてのデータ取得・更新に事業所単位の絞り込みを必須化
  • 事業所の識別情報は画面からの入力ではなくログイン情報から導出
  • 職員・事業所管理者・当社サポートで権限を分離
  • 職員用／当社管理用／転記用PC／フォームで通信経路を分離
03
介護ソフトのID・パスワードを当社が持たない
  • 入力は事業所の転記用PC上でのみ行う
  • 保管先はWindows標準のCredential Manager
  • 当社サーバー・DB・管理画面・ログのいずれにも残さない
04
AIの取り扱い
  • お客様のデータをAIの学習目的に利用しません
  • 利用するAI基盤も、学習に利用されない契約・設定の範囲で使います
  • AIへ送るのは記録作成に必要な範囲のみ
  • 文字起こし全文・整形結果全文はログや通知に出さない
05
暗号化と個人情報の扱い
  • 通信はTLS 1.2以上
  • 保存時暗号化に加え、記録本文・文字起こし・利用者氏名など個人情報にあたる項目は個別に暗号化（AES-GCM）
  • 管理画面では氏名・メールを伏字化。伏字なしの閲覧は理由の記録付きで担当者に限定
  • ケアマネジメント記録は要配慮個人情報を含み得る情報として慎重に扱う
06
アカウント管理・端末管理
  • 「誰が何を見たか」をアクセス履歴として記録（IP・端末情報はハッシュ化）
  • 職員は自分のログイン中デバイス一覧から他端末をサインアウトできる
  • 事業所管理者は職員を招待・停止・削除・再開可能。退職時は停止するだけで以後の操作が即座にできなくなる
  • 転記用PCは1事業所1台。新規登録で旧PCを自動的に無効化し置換履歴を監査ログに残す
委託先　配信・データベース・認証・音声認識・AI整形・障害監視には、国内外のクラウド事業者を利用します。保存地域・処理地域と委託契約の状況は、ご契約時に一覧でご提示します。

保持期間　音声ファイルは最大24時間の一時保存、文字起こし・AI利用ログは180日、記録本体は契約期間中＋解約後30日、監査ログは2年（契約でより短い期間も設定できます）。
Requirements

ご利用にあたって必要な環境。

記録入力を行う端末と、介護ソフトへの自動転記を行うPCは別に必要です。

For Staff
記録入力に使う端末
  • Windows 11 PC＋Microsoft Edge またはGoogle Chromeの最新版
  • macOS＋Safari またはGoogle Chromeの最新版
  • Cookie・JavaScriptが有効／ログイン用メールを受信できること
  • iPhoneはiOS 18.4以上＋Safari最新版。AndroidはサポートされているOS＋Google Chrome最新版
  • タブレット（iPad・Androidタブレット）は標準の推奨環境に含みません
  • Windows 10・Chromebook・Firefox・Internet Explorerは非対応
For Transfer
自動転記に使うPC（事業所に1台）
  • Windows 11 64bit／Windows Update適用済み
  • 業務時間中は起動しておけるPC（共有PCである必要はありません）
  • 安定したインターネット接続
  • アプリのインストールと自動起動が許可されていること
  • 1事業所につき1台。新しいPCを登録すると、古いPCは無効になります
ご注意　ログイン、記録入力・送信、音声アップロード、AI整形、転記予約、自動転記のすべてにインターネット接続が必要です。オフラインでは記録の作成・送信・転記予約はできません。
Disclosures

あらかじめご了承いただきたい事項。

導入後に起こりうる事象と、その際の当社対応を隠さずご説明します。

起こりうる事象影響当社および事業所の対応
介護ソフト側の画面仕様変更 自動転記が一時停止します。記録の作成・保存は継続できます 当社が検知して転記を止め、対応版を配布します。復旧までは手入力へ切り替えていただきます（復旧時間は外部システム側の変更内容によるため保証できません）
保存できたか判別できない転記 該当記録の転記が保留になります 二重登録を防ぐため自動で再実行しません。介護ソフトの画面で保存有無をご確認いただき、結果に応じて再実行します
転記用PCの停止・ネットワーク断 停止中は転記が進みません 当社の管理画面で端末の稼働状況を監視します。長時間停止時はご連絡し、必要に応じて端末の入れ替え手順をご案内します
介護ソフトのログイン失敗・アカウントロック 自動転記が失敗します 当社はID・パスワードを閲覧しないため、事業所側で再入力いただきます。当社はエラー内容と失敗箇所をお伝えします
インストール時の警告表示 初回インストール時にWindowsのSmartScreen警告が出ます 現時点では想定された挙動です（配布本数が一定数に達した段階でコード署名の導入を予定）。以降の自動更新は署名検証を行います
AI整形の内容 整形結果が意図と異なる場合があります 確定前に必ず職員が確認・修正する運用を前提としています。記録内容の最終責任は事業所側にあります
